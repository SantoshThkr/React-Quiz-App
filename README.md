# React Quiz App

A simple quiz application built with React.

## Features

- Multiple-choice questions
- Score calculation
- Progress indicator
- Result screen
- Restart quiz
- Responsive UI

## Tech Stack

- React
- JavaScript
- CSS
- Jest
- React Testing Library

## Installation

```
npm install
```

## Run

```
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Test

```
npm test
```
