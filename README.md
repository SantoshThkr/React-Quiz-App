# React Quiz App

A simple quiz app built with React.

## Features

* Multiple-choice questions
* Score calculation
* Progress indicator
* Result screen
* Restart quiz
* Responsive UI

## Tech Stack

* React
* JavaScript
* CSS
* Jest
* React Testing Library

## Setup

```bash
npm install
```

Run the app:

```bash
npm start
```

Open `http://localhost:3000`.

## Test

```bash
npm test
```
